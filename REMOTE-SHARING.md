# Remote Sharing

To let someone far away install and use the app, you need two things:

1. A public backend URL.
2. A build of the app that points to that backend.

## 1. Set the backend URL

Update `.env` with a public API URL:

```bash
EXPO_PUBLIC_API_URL=https://your-public-api-domain.com
```

Use the same value in your EAS build environment.

## 2. Build the app

For quick testing with a link you can send to someone:

```bash
eas build --profile preview --platform android
```

For a production release:

```bash
eas build --profile production --platform android
```

## 3. Share it

- Android: send the install link or APK generated by EAS.
- iPhone: use TestFlight or an internal iOS build.

## Important

- Local IPs like `172.20.x.x` will not work for someone far away.
- The backend must be reachable from the public internet.
- Payment, login, workouts, and notifications all depend on the backend being online.
npx expo start --tunnel
